01 / THE IDEA

A friendlier label
for a familiar number.

Some IDs are easier to spot in a log or say aloud when they have words attached. random_names maps number chunks into a bundled word list, then can look the words up again.

01

Choose your number

Pass an integer together with a prefix and a post-type marker.

48342342 integer
02

Get a stable name

The same inputs use the same bundled words each time.

id_q_cut_jami name
03

Reverse it

Decode names using the supported _q_ or _a_ marker.

48342342 recovered
02 / IN PYTHON

Two functions.
One round trip.

This is a real output from the bundled word list. The library keeps the mapping local and deterministic.

Function guide ↗
example.pyPYTHON 3.11+
from random_names.make_name import (
    number_from_name,
    number_to_name,
)

name = number_to_name(48342342, "id", "q")
assert name == "id_q_cut_jami"

number = number_from_name(name)
assert number == 48342342
03 / USE IT WITH CARE

Memorable is
still an identifier.

The name is deliberately reversible, so it is not a secret or a security token. Keep the word list consistent across systems that exchange these names.
